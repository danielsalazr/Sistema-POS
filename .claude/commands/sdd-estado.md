---
description: Muestra el estado de las features SDD y qué sigue en cada una
argument-hint: [NNN]
---

1. Ejecuta `npm run sdd:estado` (también regenera `sdd/features/README.md`).
2. Si se indicó una feature ($ARGUMENTS), lee sus documentos y resume la fase actual, lo que falta para aprobarla (preguntas abiertas, secciones incompletas, tareas pendientes) y el siguiente comando a usar (`/sdd-spec`, `/sdd-design`, `/sdd-plan` o `/sdd-implementar`).
3. Si no se indicó, presenta la tabla y la siguiente acción de cada feature activa.
